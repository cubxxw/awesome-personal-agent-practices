# Maintaining this resource collection

- Scope: personal-agent products, directly related open-source projects, public use cases, articles and research. Resource aggregation is the main deliverable.
- Update `data/catalog.json`; regenerate both languages with `python3 scripts/catalog.py`, then run `python3 scripts/catalog.py --check`.
- Read original public sources before changing factual annotations. A working link or search snippet does not establish a full-source review.
- Keep source context: vendor claims, author reports, implementation notes, research and synthetic examples are different kinds of evidence.
- Do not import private research files, transcripts, account data, API responses, secrets or signed URLs.
- Prefer brief descriptions and categorized pages. Do not turn the homepage into a scorecard or a product implementation guide.
- Preserve stable IDs and original attribution; record moved projects and renamed products accurately.
- Update dates only for sources actually reviewed. No automatic promotion of a reported outcome to a reproduced result.
