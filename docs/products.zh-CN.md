<a id="computer"></a>
## 电脑与浏览器助手

<a id="products-today-ai"></a>
- **[Today](https://today.ai/)** — 结合可编辑记忆、周期任务和应用连接的个人Agent，适合关注日程、邮件、研究及跨设备工作流。
  <sub>官方说明</sub>

<a id="products-grok-bot"></a>
- **[Grok Bot](https://x.ai/bot)** — 拥有独立电脑、能使用连接工具并交回成果的持续运行 AI 队友，适合关注个人与团队任务委托。
  <sub>官方说明</sub>

<a id="products-manus-cue"></a>
- **[Cue by Manus](https://www.cue.im/)** — Manus 的独立个人Agent 应用，可创建不同身份与职责的 Agent，适合关注多助理分工、周期任务及手机端审阅。
  <sub>官方说明</sub>

<a id="products-manus"></a>
- **[Manus](https://manus.im/)** — 面向研究、交付物及浏览器与电脑工作的通用任务 Agent，适合关注多步项目、本地文件及周期或事件触发自动化。
  <sub>官方说明</sub>

<a id="products-claude-cowork"></a>
- **[Claude / Cowork](https://claude.com/product/cowork)** — 跨文件、连接工具与内置浏览器执行知识工作的助理，适合关注文档、表格及周期报告；官方页面说明 Cowork 正并入 Claude。
  <sub>官方说明</sub>

<a id="products-cue-desktop"></a>
- **[Cue桌面助手（heycue.io）](https://heycue.io/)** — 面向Mac和Windows的语音写作、屏幕上下文问答、任务与会议记录助手。与Manus Cue及heycue.ai生活事务产品分开。
  <sub>官方说明</sub>

<a id="messaging"></a>
## 消息入口的助手

<a id="products-instinct"></a>
- **[Instinct](https://instinct.com/)** — 可以发消息或打电话委托的个人助理，官方介绍包括电话与电脑操作，适合关注预约、采购和出行等现实事务。
  <sub>官方说明</sub>

<a id="products-poke"></a>
- **[Poke](https://poke.com/)** — 从聊天入口连接应用和服务的助理，适合关注提醒与日常自动化；官网列出 Messages、WhatsApp 和 Telegram。
  <sub>官方说明</sub>

<a id="products-town"></a>
- **[Town](https://www.town.com/)** — 学习工作上下文并连接邮件、日历、文档和工具的助理，适合关注个人化工作习惯与不同渠道中的 Townie。
  <sub>官方说明</sub>

<a id="ecosystem"></a>
## 平台生态的助手

<a id="products-meta-muse"></a>
- **[Muse by Meta](https://ai.meta.com/muse/)** — Meta 的个人Agent，拥有云端电脑与浏览器，可通过 Muse 应用或 WhatsApp 交流，适合关注持续目标和跨应用任务。
  <sub>官方说明</sub>

<a id="products-chatgpt-dots"></a>
- **[Dots in ChatGPT](https://chatgpt.com/features/dots/)** — ChatGPT 中拥有云端电脑、应用连接与持续职责的 Agent，适合关注长期委托以及可配置的访问权限。
  <sub>官方说明</sub>

<a id="products-gemini-spark"></a>
- **[Gemini Spark](https://gemini.google/overview/agent/spark/)** — Google 的后台个人Agent，通过任务、技能与调度连接 Google 应用，适合关注邮件、文档及周期性 Workspace 工作流。
  <sub>官方说明</sub>

<a id="products-siri-ai"></a>
- **[Siri / Siri AI](https://www.apple.com/apple-intelligence/)** — Apple 系统中的个人上下文与应用操作助理，适合关注设备信息、语音及受支持应用动作怎样连接日常任务。
  <sub>官方说明</sub>

<a id="family-goals"></a>
## 家庭与个人目标

<a id="products-tomo-mapo"></a>
- **[Tomo by Mapo Labs](https://www.tomo.ai/)** — 由 Mapo Labs 开发、以短信交流的个人 AI，适合关注目标陪伴、主动提醒、群聊以及日历和邮件连接。
  <sub>官方说明</sub>

<a id="products-ollie"></a>
- **[Ollie](https://ollie.ai/)** — 面向家庭日历、邮箱信息和家庭协作的助理，适合关注短信与家庭群聊中的事务协调。
  <sub>官方来源，部分核读</sub>

<a id="products-heycue-life-admin"></a>
- **[HeyCue](https://heycue.ai/)** — 管理账单、续订与本地服务报价的生活事务产品，结合 Agent 和人工代表，适合关注家庭需求如何变成报价及确认流程。
  <sub>官方说明</sub>
