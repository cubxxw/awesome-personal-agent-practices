<a id="proactivity"></a>
## 主动性与任务续接

<a id="research-vitabench2"></a>
- **[VitaBench 2.0](https://arxiv.org/html/2605.27141v1)** — 研究连续任务中的偏好变化与主动补问，并提供可比较的记忆接口。使用构造历史，不能等同真实账户跨月体验。
  <sub>研究材料</sub>

<a id="research-pi-bench"></a>
- **[π-Bench](https://arxiv.org/html/2605.14678v3)** — 通过隐藏意图、任务依赖和跨会话续接考察主动助手。采用模拟用户及统一执行框架，结论不能直接套到所有上线产品。
  <sub>研究材料</sub>

<a id="research-vibelife"></a>
- **[VibeLifeBench](https://arxiv.org/abs/2608.10875v2)** — 介绍变化模拟环境中的多周生活助手任务，关注行动时机与隐含约束。本条只依据摘要，尚未精读完整方法。
  <sub>研究材料</sub>

<a id="memory"></a>
## 记忆与个性化

<a id="research-memora"></a>
- **[Memora: From Recall to Forgetting](https://arxiv.org/html/2604.20006v1)** — 考察用户信息变化后的记忆、推理与推荐，用遗忘指标识别过时记忆。对话是模拟数据，适合借用测试问题。
  <sub>研究材料</sub>

<a id="research-pasb"></a>
- **[PASB: Agents Don’t Just Agree, They Remember](https://arxiv.org/html/2607.10526v1)** — 研究用户说法如何进入记忆并影响后续会话，适合思考记忆写入规则。受控对话实验不能证明日常执行可靠性。
  <sub>研究材料</sub>

<a id="research-longmint"></a>
- **[LongMINT](https://arxiv.org/html/2605.18565v1)** — 测试变化信息中的当前事实、历史与先后顺序，帮助区分记住旧事实和用对当前事实。属于离线问答评测。
  <sub>研究材料</sub>

<a id="research-personalized-rag"></a>
- **[Awesome Personalized RAG Agent / survey](https://github.com/Applied-Machine-Learning-Lab/Awesome-Personalized-RAG-Agent)** — 按个性化检索和Agent方法整理论文、数据与评测，适合顺着地图找原始研究。具体技术仍需回到论文核读。
  <sub>资源集合</sub>

<a id="evaluation"></a>
## 评测方法

<a id="research-recuris"></a>
- **[Recuris](https://arxiv.org/html/2608.24876v1)** — 连接可核验任务状态、失败轨迹和针对性技能修复。基准中的改进不等于真实生活中无人值守的可靠性。
  <sub>研究材料</sub>

<a id="research-personal-agent-bench"></a>
- **[Personal Agent Bench](https://personalagentbench.com/)** — 将运行机制拆解与模拟任务结果并列。Zentor团队披露自身Agent业务关联，部分聚合成绩缺完整公开运行记录。
  <sub>研究材料</sub>

<a id="research-micro1-personalagentbench"></a>
- **[micro1 PersonalAgentBench launch](https://www.linkedin.com/posts/aliansarinik_which-personal-agent-is-the-best-life-assistant-activity-7513263537247457282-D1-5)** — 创始人介绍四款个人Agent的日常任务与信任测试，并邀请用户贡献。本条只核读发布文字，没有验证外链成绩。
  <sub>官方说明</sub>
