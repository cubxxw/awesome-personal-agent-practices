## 先看这些

- [Poke](docs/products.zh-CN.md#products-poke) — 从聊天入口连接应用和服务的助理，适合关注提醒与日常自动化；官网列出 Messages、WhatsApp 和 Telegram。
- [Hermes Agent](docs/projects.zh-CN.md#projects-hermes-agent) — Nous Research 的个人Agent，结合持久记忆、可复用技能、消息入口和定时工作，可在本机或远程环境运行。定时结果送达需要持续运行的 gateway 或已配置的托管调度。
- [OpenMuse](docs/projects.zh-CN.md#projects-openmuse) — CopilotKit 的个人Agent 应用模板，把邮件、日历、持久浏览器、任务进展和动作审批放在同一工作面。当前为适合自托管和二次开发的 alpha，相关集成需要单独配置。
- [Hermes数月使用：六邮箱与复用流程](docs/use-cases.zh-CN.md#use-cases-uc03) — 用户自报数月用Hermes分拣六个邮箱、积累可复用流程，发送仍由本人控制。记录同时包含过时记忆维护与昂贵模型自动回退的教训。
- [用WhatsApp更新舞蹈学校网站](docs/use-cases.zh-CN.md#use-cases-uc01) — 作者自报把小型舞校网站连到WhatsApp和GitHub，母亲可通过聊天更新。初始化权限与可靠回滚仍需技术熟手帮忙。
